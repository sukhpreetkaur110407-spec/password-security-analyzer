# 🔐 Password Security Analyzer & Generator

## 📌 Project Overview

Password Security Analyzer & Generator is an educational
cybersecurity project designed to teach users about password
security, password strength, common password attacks and
secure password practices.

The project uses only HTML5 and CSS3.

It does not use JavaScript, databases or a backend server.

---

## 🎯 Objectives

The main objectives of this project are:

- Explain the importance of strong passwords.
- Educate users about password security.
- Explain common password attacks.
- Provide password security guidelines.
- Demonstrate recommended password characteristics.
- Provide a simple and responsive cybersecurity interface.

---

## ✨ Features

### Password Security Analyzer

The project provides information about:

- Password length
- Uppercase characters
- Lowercase characters
- Numbers
- Special characters
- Password uniqueness
- Predictability

### Password Strength Guide

Passwords are categorized into:

1. Very Weak
2. Weak
3. Fair
4. Strong
5. Very Strong

### Password Generator Guide

The project demonstrates recommended password:

- Length
- Character types
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

### Security Education

The website explains:

- Brute-force attacks
- Dictionary attacks
- Credential stuffing
- Password spraying
- Multi-factor authentication
- Password managers
